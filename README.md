# 🔢 Advanced Web Calculator

A modern, responsive **web-based calculator** built using **HTML, CSS, and JavaScript** with a clean UI and advanced mathematical capabilities.

---

## 🚀 Features

- 🧮 Basic arithmetic operations (+, −, ×, ÷, %)
- 🔬 Scientific functions:
  - sin(x)
  - cos(x)
  - log(x)
  - √ (square root)
- π (Pi) and ∞ (Infinity) support
- ⌨️ Keyboard input support
- 📜 Calculation history panel
- 🎨 Modern glassmorphism UI design
- ⚡ Real-time calculations with error handling

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Glassmorphism)
- JavaScript (DOM Manipulation, Math Functions)
